# 봄버 미로

폭탄으로 상자를 부수고 적을 없애 숨어 있는 출구로 탈출하는 액션 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나.

- 방향 버튼(또는 방향키·WASD)으로 걷고, 💣 버튼(Space)으로 폭탄을 놓는다. 폭탄은 2.2초 뒤 십자로 터진다
- 폭발은 **내가 맞아도** 목숨이 깎인다. 놓고 도망치는 동선이 핵심. 불길이 닿은 폭탄은 연쇄로 터진다
- 판마다 쓸 수 있는 폭탄 개수가 정해져 있고(동시에 2개까지), 상자 속 아이템(💣 +1 · 🔥 불길 +1 · ❤️ 목숨 +1)으로 늘릴 수 있다
- 출구는 상자 하나 밑에 숨어 있고, 적을 모두 없애야 열린다. 슬라임은 어슬렁거리고 유령은 쫓아온다
- 폭탄을 다 쓰고 더 못 푸는 판이 되면 목숨 1개를 잃고 그 판을 다시 한다
- 점수 = 클리어 + 빨리 깰수록(속도) + 남은 목숨 + 아낀 폭탄 + 잡은 적. 최고 점수(`bomberBest`)를 저장한다
- 판은 매번 새로 만든다. 출구·적에게 가는 길은 늘 상자만 부수면 닿도록 만들고, 폭탄 개수는 그 길을 뚫는 데 필요한 만큼 계산해 준다

`index.html` 을 그대로 열면 된다. 규칙·판 만들기는 `logic.js`, 화면·입력은 `game.js`.
